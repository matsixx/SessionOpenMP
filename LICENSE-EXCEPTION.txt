NOTE FOR ANYONE REPLACING THE TRANSPORT
---------------------------------------
The transport seam (src/transport/transport.h) exists so that EOS can be swapped for
a different backend. A build that uses only GPL-compatible transports -- the shared
memory backend, or a future direct-UDP one -- does not rely on this exception at all
and is plain GPLv3.
